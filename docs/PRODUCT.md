# Lifora Product Brief

## Product
Lifora

## Mode
University Student Mode

## Central question
> Given everything happening in my life right now, what is the smartest thing I should do next?

Lifora brings a student's competing priorities into context and recommends a useful next step.

## Core MVP
- Persistent student state
- Academic Agent
- Finance Agent
- Balance Agent
- Coordinator Agent
- Best Next Action
- Daily Plan
- Decision Trace
- Deadline Risk
- Dynamic Replanning

## Stretch
- Smart Task Breakdown
- What-If Simulator

## Product boundary
The initial dashboard is a shell. It does not yet implement agents, saved state, recommendations, or simulation. Build the MVP incrementally; preserve clear, explainable recommendations and update them when the student's state changes.
